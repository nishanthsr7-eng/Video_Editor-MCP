Video Editor - MCP Tools Workflow
============================================

Prerequisites:
- ffmpeg and ffprobe must be installed and available on PATH
  (e.g. installed via: winget install Gyan.FFmpeg)
- uv (Python package manager) must be installed
  (e.g. installed via: winget install astral-sh.uv)

Setup:
- D:\Files\Projects\Multi-Agent Orchestration Framework for Generative Video Editing\.mcp.json registers twenty MCP servers:
    "ffmpeg-mcp"              -> Tools\Frame_Extractor_MCP
    "character-extractor-mcp" -> Tools\Character_Extractor_MCP
    "text-overlay-mcp"        -> Tools\Text_Overlay_MCP
    "Video_edit_MCP"          -> third-party PyPI package "video-edit-mcp"
                                 (run via "uvx video-edit-mcp", no local
                                 folder/uv sync needed)
    "audio-analyzer-mcp"      -> Tools\Audio_Analyzer_MCP
    "effects-mcp"             -> Tools\Effects_MCP
    "scene-detector-mcp"      -> Tools\Scene_Detector_MCP
    "compositor-mcp"          -> Tools\Compositor_MCP
    "highlight-reel-mcp"      -> Tools\Highlight_Reel_MCP
    "audio-mastering-mcp"     -> Tools\Audio_Mastering_MCP
    "color-match-mcp"         -> Tools\Color_Match_MCP
    "export-presets-mcp"      -> Tools\Export_Presets_MCP
    "timeline-project-mcp"    -> Tools\Timeline_Project_MCP
    "lut-grading-mcp"         -> Tools\LUT_Grading_MCP
    "chroma-key-mcp"          -> Tools\Chroma_Key_MCP
    "stabilization-mcp"       -> Tools\Stabilization_MCP
    "ken-burns-mcp"           -> Tools\Ken_Burns_MCP
    "speed-ramp-mcp"          -> Tools\Speed_Ramp_MCP
    "overlay-fx-mcp"          -> Tools\Overlay_FX_MCP
    "beat-sync-mcp"           -> Tools\Beat_Sync_MCP
- Restart Claude Code (or reconnect MCP servers) after any code change
  in these tools, so the new code is loaded.
- To sync/install dependencies for the custom tools:
    cd "D:\Files\Projects\Multi-Agent Orchestration Framework for Generative Video Editing\Tools\<tool folder>"
    uv sync


============================================
ffmpeg-mcp tools (Tools\Frame_Extractor_MCP)
============================================

1) get_video_info
   What it does: Returns video metadata (duration, resolution, fps,
   codec, bitrate, audio info, etc.) via ffprobe.
   Input: video_path (str) - path to a video file.
   Output: JSON-like dict of stream info. Nothing is written to disk.
   Usage: get_video_info(video_path="D:\...\Sources\my_clip.mp4")

2) find_video_path
   What it does: Recursively searches a folder for a video file by
   name (with or without extension) and returns its full path.
   Input: root_path (str) - folder to search; video_name (str) - file
   name to match (extension optional).
   Output: full path string of the first match, or "" if not found.
   Usage: find_video_path(root_path="D:\...\Sources", video_name="my_clip")

3) extract_frames_from_video
   What it does: Extracts every frame (or every Nth second) of a video
   as individual images using ffmpeg.
   Input: video_path (str) - source video file.
   Optional params:
     - fps (int): 0 = extract every frame (default), 1 = one frame per
       second, N = one frame every N seconds.
     - output_folder (str): where to save frames. If not given,
       defaults to:
         D:\Files\Projects\Multi-Agent Orchestration Framework for Generative Video Editing\Output\<video name>\
       (<video name> = video filename without extension)
     - format (int): 0=png (default), 1=jpg, 2=webp
     - total_frames (int): max number of frames to extract, 0 = no limit
   Output: frame_0001.<ext>, frame_0002.<ext>, ... saved in output_folder.
   Usage:
     extract_frames_from_video(video_path="D:\...\Sources\my_clip.mp4")
     -> D:\Files\Projects\Multi-Agent Orchestration Framework for Generative Video Editing\Output\my_clip\frame_0001.png ...

4) enhance_frames
   What it does: Upscales/enhances a folder of image frames using
   Real-ESRGAN (ncnn-vulkan, GPU-accelerated via Vulkan). Useful for
   improving the quality of frames extracted in step 3, especially
   for anime.
   Binary: Tools\RealESRGAN\realesrgan-ncnn-vulkan.exe
           (from xinntao/Real-ESRGAN v0.2.5.0 release, bundled anime
           models in Tools\RealESRGAN\models)
   Input: input_folder (str) - folder of images (e.g. the output of
   extract_frames_from_video).
   Optional params:
     - output_folder (str): where to save enhanced images. If not
       given, defaults to "<input_folder>_enhanced".
     - model (str): "realesrgan-x4plus-anime" (default, best for anime),
       "realesrgan-x4plus" (general purpose), "realesr-animevideov3"
       (faster, anime video)
     - scale (int): upscale factor 2/3/4 (default 4). Use 2 for a more
       modest upscale (faster, smaller files).
     - format (int): output image format, 0=png (default, lossless,
       large), 1=jpg (lossy, smaller), 2=webp
     - in_place (bool): if True, overwrite the original frames in
       input_folder instead of writing to output_folder (old files are
       deleted, new files keep the frame_NNNN naming with the new
       extension).
   Output: enhanced frame_0001.<ext>, frame_0002.<ext>, ... in
   output_folder (or back in input_folder if in_place=True).
   Usage:
     enhance_frames(input_folder="D:\...\Output\my_clip")
     -> D:\...\Output\my_clip_enhanced\frame_0001.png ... (4x upscale, png)

     enhance_frames(input_folder="D:\...\Output\my_clip", scale=2,
                     format=1, in_place=True)
     -> overwrites D:\...\Output\my_clip\frame_0001.jpg ... (2x upscale, jpg)

5) clip_video
   What it does: Cuts a section out of a video using ffmpeg.
   Input: video_path (str) - source video file.
   Optional params:
     - start (int/float/str): start time (seconds, "MM:SS", or
       "HH:MM:SS"). Defaults to start of video. If negative/omitted
       together with end, clips from the end backwards.
     - end (int/float/str): end time (same formats). Either end or
       duration must be given.
     - duration (int/float/str): clip length instead of end time.
     - output_path (str): output file path. If not given, a default
       path next to the source file is used (e.g. "<name>_clip.<ext>").
     - time_out (int): command timeout in seconds, default 300.
   Output: a new video file at output_path.
   Usage: clip_video(video_path="D:\...\my_clip.mp4", start="00:01:30", end="02:30")

6) scale_video
   What it does: Resizes a video to a target resolution.
   Input: video_path (str), width (int), height (int) (-2 = keep aspect
   ratio, rounded to nearest even number).
   Optional: output_path (str) - default "<name>_clip.<ext>" next to source.
   Output: resized video file at output_path.
   Usage: scale_video(video_path="D:\...\my_clip.mp4", width=1920, height=-2)

7) overlay_video
   What it does: Overlays one video on top of another (picture-in-picture),
   also mixes their audio tracks.
   Input: background_video (str), overlay_video (str).
   Optional params:
     - output_path (str): output file path (default generated next to source).
     - position (int): 1=TopLeft, 2=TopCenter, 3=TopRight, 4=RightCenter,
       5=BottomRight, 6=BottomCenter, 7=BottomLeft, 8=LeftCenter, 9=Center.
     - dx, dy (int): pixel offsets from the chosen position.
   Output: combined video file at output_path.
   Usage:
     overlay_video(background_video="D:\...\bg.mp4", overlay_video="D:\...\fg.mp4",
                    position=5, dx=-20, dy=-20)

8) concat_videos
   What it does: Concatenates multiple videos into one using ffmpeg.
   Input: input_files (List[str]) - ordered list of video file paths.
   Optional params:
     - output_path (str): output file path (default generated).
     - fast (bool): True (default) = fast concat, requires all inputs
       to share codec/resolution/fps. False = re-encodes, use when
       inputs differ.
   Output: combined video file at output_path (.mp4/.mkv based on extension).
   Usage: concat_videos(input_files=["a.mp4", "b.mp4"], output_path="combined.mp4")

9) play_video
   What it does: Plays a video locally using ffplay (opens a window on
   the machine running the MCP server).
   Input: video_path (str).
   Optional: speed (float, 0.5-2 recommended, default 1), loop (int,
   1=play once and exit (default), 0=loop forever).
   Output: none (interactive playback window).
   Usage: play_video(video_path="D:\...\my_clip.mp4", speed=1.5)


=========================================================
character-extractor-mcp tools (Tools\Character_Extractor_MCP)
=========================================================

10) extract_character
    What it does: Splits the anime character(s) from the background in
    each image of a folder, using the anime-segmentation ISNet ONNX
    model (CPU inference via onnxruntime, ~1-2s per frame).
    Model: Tools\Character_Extractor_MCP\models\isnetis.onnx
    (from huggingface.co/skytnt/anime-seg)
    Input: input_folder (str) - folder of frame images (e.g. output of
    extract_frames_from_video, optionally after enhance_frames).
    Optional params:
      - output_folder (str): where to save character cutouts. If not
        given, defaults to "<input_folder>_character".
      - with_background (bool): if True, also saves the background-only
        images (character area made transparent) to
        "<output_folder>_background".
      - size (int): inference resolution, default 1024 (higher = more
        detail, slower).
      - threshold (float): mask cutoff, 0 (default) = soft/antialiased
        edges (recommended), >0 (e.g. 0.5) = hard binary mask.
    Output: transparent-background PNGs (RGBA), same frame_NNNN naming
    but always .png, regardless of input format.
    Usage:
      extract_character(input_folder="D:\...\Output\my_clip")
      -> D:\...\Output\my_clip_character\frame_0001.png ... (character only)

      extract_character(input_folder="D:\...\Output\my_clip", with_background=True)
      -> also creates D:\...\Output\my_clip_character_background\frame_0001.png ...


=========================================================
text-overlay-mcp tools (Tools\Text_Overlay_MCP)
=========================================================

11) list_fonts
    What it does: Lists the bundled fonts available for add_text_overlay.
    Input: none.
    Output: list of 24 font name strings, grouped roughly as:
      - Bold display / "edit" titles: anton, bebas-neue,
        montserrat-extrabold, poppins-extrabold, oswald-bold,
        archivo-black, russo-one, black-ops-one, bungee, teko-bold,
        roboto-condensed-bold, inter-black, fredoka-bold, open-sans-bold
      - Playful / comic: bangers, lobster
      - Script / handwritten: pacifico, permanent-marker,
        dancing-script-bold, caveat-bold
      - Serif (narration/caption style): playfair-display-bold,
        lora-bold, merriweather-bold, pt-serif-bold
    Usage: list_fonts()

12) add_text_overlay
    What it does: Adds "edit"-style bold text overlays (like the
    "IT WAS YOU" reveal text seen in anime edits) to a video. Text is
    rendered with PIL using bundled fonts, with optional gradient fill,
    outline, shadow, and word-by-word reveal animation.
    Fonts: Tools\Text_Overlay_MCP\fonts - 24 free/OFL Google Fonts
    covering bold display, playful/comic, script/handwritten, and serif
    caption styles. See list_fonts() for the full set.
    Input:
      - video_path (str): source video file.
      - text (str): text to display. Use "\n" for multiple lines.
    Optional params:
      - output_folder (str): where to save outputs. If not given,
        defaults to:
          D:\Files\Projects\Multi-Agent Orchestration Framework for Generative Video Editing\Output\<video name>_text_overlay\
      - font (str): one of list_fonts(), default "anton".
      - font_size (int): pixel size. Default = ~9% of video height.
      - color (str | [str, str]): hex color, e.g. "#FFFFFF" for solid,
        or ["#FFFFFF", "#FFD700"] for a top-to-bottom gradient (white to
        gold highlight look).
      - outline_color (str): hex outline color, default "#000000".
      - outline_width (int): outline thickness in px, 0 = none (default).
        Common "edit" look: 4-10.
      - shadow (bool): add a soft drop shadow, default False.
      - position (str): "top" | "center" (default) | "bottom".
      - start_time (float): when the text starts appearing (seconds),
        default 0.
      - duration (float): how long the text stays visible (seconds).
        Default = from start_time to end of video.
      - animation (str): "none" (static), "fade" (whole text fades in),
        "word_by_word" (default - words appear one after another, the
        classic "reveal" effect), "typewriter" (words pop in quickly in
        sequence).
      - fps (float): overlay frame rate. Default = source video fps
        (capped at 30).
    Output:
      - output_folder\overlay.webm - transparent (alpha channel, VP9)
        text animation video, usable as an overlay layer in other editors.
      - output_folder\output_burned.<ext> - full video with the text
        composited (burned) into the frames, same resolution/audio as
        source.
    Usage:
      add_text_overlay(video_path="D:\...\Sources\clip.mp4", text="IT WAS YOU",
                        font="anton", color=["#FFFFFF", "#FFD700"],
                        outline_color="#000000", outline_width=6,
                        position="center", start_time=2.0, duration=2.5,
                        animation="word_by_word")
      -> D:\...\Output\clip_text_overlay\overlay.webm
      -> D:\...\Output\clip_text_overlay\output_burned.mp4


13) add_karaoke_captions
    What it does: Adds "karaoke"-style subtitles that highlight each word
    in sync with speech, using word-level timestamps. Built on the same
    PIL rendering + ffmpeg overlay/burn pipeline as add_text_overlay.
    Input:
      - video_path (str): source video file.
      - segments (List[{start, end, text, words: [{word, start, end}, ...]}]):
        word-level transcript, taken directly from audio-analyzer-mcp's
        transcribe_audio(word_timestamps=True) "segments" output.
    Optional params:
      - output_folder (str): defaults to
        D:\Files\Projects\Multi-Agent Orchestration Framework for Generative Video Editing\Output\<video name>_karaoke\
      - font (str): one of list_fonts(), default "anton".
      - font_size (int): default = ~5.5% of video height.
      - color (str): unplayed word color, default "#FFFFFF".
      - highlight_color (str): highlighted/active word color, default
        "#FFD700" (gold).
      - outline_color (str): default "#000000".
      - outline_width (int): default 6.
      - shadow (bool): default True.
      - position (str): "top" | "center" | "bottom" (default).
      - max_words_per_line (int): words per caption line, default 6.
      - fps (float): overlay frame rate. Default = source video fps
        (capped at 30).
    Output:
      - output_folder\overlay.webm - transparent karaoke caption animation.
      - output_folder\output_burned.<ext> - full video with captions burned in.
    Usage:
      result = transcribe_audio(audio_path="D:\...\Sources\clip.mp4")
      add_karaoke_captions(video_path="D:\...\Sources\clip.mp4",
                            segments=result["segments"],
                            font="anton", highlight_color="#FFD700",
                            position="bottom")

Video_edit_MCP tools (third-party: "video-edit-mcp" on PyPI)
=========================================================

14) Video_edit_MCP
    What it does: A free, MIT-licensed, third-party MCP server (MoviePy +
    yt-dlp based) that takes natural-language instructions about clips/audio
    and performs the edit directly. Run via "uvx video-edit-mcp" - not a
    local project, no uv sync needed, no source code in Tools\.
    Repo: https://github.com/Aditya2755/video-edit-mcp

    Provides ~34 tools covering:
      - Basic editing: trim, merge, resize, crop, rotate
      - Effects: speed control, fade in/out, grayscale, mirror
      - Overlays: add text/image/video overlays with transparency
      - Format conversion with codec control
      - Frame operations: extract frames, build video from image sequence
      - Audio: extract/trim/loop/concat audio, volume/fade, mixing multiple
        tracks, replace a video's soundtrack
      - Video download (YouTube/other platforms via yt-dlp)
      - In-memory object store, so operations can be chained across tool
        calls without re-specifying file paths each time

    Input/Output: no fixed default output folder like the custom tools -
    when invoking, point outputs at
    D:\Files\Projects\Multi-Agent Orchestration Framework for Generative Video Editing\Output\<name>\ explicitly.

    Overlap note: some functionality overlaps ffmpeg-mcp (clip_video,
    scale_video, concat_videos, overlay_video) and text-overlay-mcp
    (text/image overlays). Use Video_edit_MCP mainly for what the custom
    tools don't cover yet: audio mixing/soundtrack replacement, speed/
    fade/grayscale/mirror effects, image-sequence -> video, and downloads.


=========================================================
audio-analyzer-mcp tools (Tools\Audio_Analyzer_MCP)
=========================================================

Analyzes the audio track of a video (or a standalone audio file) using
librosa (beat/tempo, transients, spectral features) and faster-whisper
(local speech-to-text). If given a video file, the audio track is extracted
automatically via ffmpeg. Nothing is written to disk - all tools return
data only.

15) get_audio_info
    What it does: Returns basic audio info - duration, sample rate, overall
    loudness (RMS mean/max).
    Input: audio_path (str) - audio or video file path.
    Output: {duration, sample_rate, rms_mean, rms_max}
    Usage: get_audio_info(audio_path="D:\...\Sources\clip.mp4")

16) detect_beats
    What it does: Detects tempo (BPM) and beat timestamps, for rhythm-
    synced cuts (e.g. cut on every beat, or trigger text/effects on beats).
    Input: audio_path (str).
    Optional params: start_time (float, default 0), duration (float,
    default to end of file).
    Output: {tempo_bpm, beat_times: [seconds...], beat_count}
    Usage: detect_beats(audio_path="D:\...\Sources\clip.mp4")

17) detect_impacts
    What it does: Detects "impact"/transient moments (drum hits, sudden
    loudness changes) with a relative strength score (0-1). Useful for
    transitions, effect triggers, or text pop-ins.
    Input: audio_path (str).
    Optional params: start_time (float, default 0), duration (float,
    default to end of file), sensitivity (float, default 1.0 - higher =
    more detected transients).
    Output: {impact_count, impacts: [{time, strength}, ...]}
    Usage: detect_impacts(audio_path="D:\...\Sources\clip.mp4", sensitivity=1.5)

18) analyze_audio_features
    What it does: Per-window analysis of RMS (loudness), spectral centroid
    ("brightness"), and zero-crossing rate, plus overall summary stats.
    Useful for finding the loudest/brightest/quietest parts of a clip.
    Input: audio_path (str).
    Optional params: start_time (float, default 0), duration (float,
    default to end of file), window (float, default 1.0 seconds).
    Output: {window_seconds, windows: [{time, rms, spectral_centroid,
    zero_crossing_rate}, ...], summary: {rms_mean, rms_max,
    spectral_centroid_mean, zero_crossing_rate_mean}}
    Usage: analyze_audio_features(audio_path="D:\...\Sources\clip.mp4", window=0.5)

19) transcribe_audio
    What it does: Local speech-to-text via faster-whisper, with word-level
    timestamps ("audio text"). Useful for auto-generating captions or
    timing text-overlay-mcp animations to spoken words.
    First call for a given model_size downloads model weights from
    huggingface (needs internet once, then cached).
    Input: audio_path (str).
    Optional params: model_size (str, "tiny"|"base" (default)|"small"|
    "medium"|"large-v3"), language (str, e.g. "en"/"ja", default
    auto-detect), word_timestamps (bool, default True).
    Output: {language, language_probability, text, segments: [{start, end,
    text, words: [{word, start, end}, ...]}, ...]}
    Usage: transcribe_audio(audio_path="D:\...\Sources\clip.mp4", model_size="base")

20) detect_downbeats
    What it does: Detects tempo (BPM) and downbeat timestamps (the first
    beat of each bar), for song-structure-aware cuts (e.g. cut on every
    bar instead of every beat).
    Input: audio_path (str).
    Optional params: start_time (float, default 0), duration (float,
    default to end of file), beats_per_bar (int, default 4).
    Output: {tempo_bpm, beats_per_bar, downbeat_times: [seconds...],
    downbeat_count}
    Usage: detect_downbeats(audio_path="D:\...\Sources\clip.mp3")

21) detect_sections
    What it does: Segments a song into structural sections (intro, verse,
    build, drop, chorus, outro) based on timbre/harmony similarity (MFCC +
    chroma agglomerative clustering) and labels each section by its
    relative energy (RMS). Useful for finding the "drop"/chorus to sync
    the most intense edits to, or for picking intro/outro points.
    Input: audio_path (str).
    Optional params: start_time (float, default 0), duration (float,
    default to end of file), n_sections (int, default auto-estimated from
    duration, clamped to 2-8).
    Output: {sections: [{label, start, end, energy}, ...]} where label is
    one of "intro"|"verse"|"build"|"drop"|"chorus"|"outro" and energy is
    normalized 0-1 (1.0 = loudest section).
    Usage: detect_sections(audio_path="D:\...\Sources\song.mp3")


=========================================================
effects-mcp tools (Tools\Effects_MCP)
=========================================================

Applies ffmpeg-filter-based "edit style" visual effects and transitions to
video clips. No extra Python dependencies beyond ffmpeg/ffprobe on PATH.

22) list_effects
    What it does: Lists the available effect names and what each one does.
    Input: none.
    Output: dict of {effect_name: description}. Effects include:
      zoom_punch, shake, rgb_split, flash, vignette, glow, film_grain,
      light_leak, speed_ramp, grade_warm, grade_cool, grade_high_contrast,
      grade_faded, grade_punchy.
    Usage: list_effects()

23) apply_effect
    What it does: Applies one named effect to a video (optionally only
    within a start/end time window), preserving audio.
    Input: video_path (str), effect (str) - one of list_effects().
    Optional params:
      - intensity (float, default 1.0): strength multiplier, effect-
        dependent (e.g. for flash/shake/glow/grain, higher = stronger).
      - start_time (float, default 0), duration (float, default = rest
        of video): time window the effect applies to (effects fade/trigger
        within this window via ffmpeg's between()).
      - output_path (str): defaults to
        D:\Files\Projects\Multi-Agent Orchestration Framework for Generative Video Editing\Output\<video name>\<video name>_<effect>.<ext>
    Output: new video file at output_path.
    Usage:
      apply_effect(video_path="D:\...\Sources\clip.mp4", effect="zoom_punch",
                    start_time=1.0, duration=0.5, intensity=1.2)
      apply_effect(video_path="D:\...\Sources\clip.mp4", effect="grade_punchy")

24) list_transitions
    What it does: Lists the ~50 transition names available for
    apply_transition (ffmpeg's xfade filter presets, e.g. "fade",
    "dissolve", "wipeleft", "circleopen", etc.).
    Input: none.
    Output: list of transition name strings.
    Usage: list_transitions()

25) apply_transition
    What it does: Joins two videos with a crossfade-style transition
    (ffmpeg xfade for video, acrossfade for audio if both clips have
    audio). The second clip's transition starts as the first clip ends.
    Input: video_a (str), video_b (str).
    Optional params:
      - transition (str, default "fade"): one of list_transitions().
      - duration (float, default 0.5): transition length in seconds.
      - output_path (str): defaults to
        D:\Files\Projects\Multi-Agent Orchestration Framework for Generative Video Editing\Output\<video_a name>_<video_b name>_transition.<ext>
    Output: new combined video file at output_path.
    Usage:
      apply_transition(video_a="D:\...\Output\clip_a.mp4",
                        video_b="D:\...\Output\clip_b.mp4",
                        transition="dissolve", duration=0.75)


=========================================================
scene-detector-mcp tools (Tools\Scene_Detector_MCP)
=========================================================

Wraps PySceneDetect's content-aware shot detector to find/split shots
within a video. Requires ffmpeg on PATH (used by split_scenes).

26) detect_scenes
    What it does: Detects shot/scene-change points in a video based on
    frame-content changes. Useful for understanding what shots a source
    clip contains before deciding what to extract/edit.
    Input: video_path (str).
    Optional params: threshold (float, default 27.0) - lower = more
    sensitive (more detected cuts); min_scene_len (int, default 15) -
    minimum shot length in frames.
    Output: {scene_count, scenes: [{index, start, end, duration}, ...]}
    Usage: detect_scenes(video_path="D:\...\Sources\clip.mp4")

27) split_scenes
    What it does: Detects shot/scene-change points and splits the video
    into one file per shot (ffmpeg). Useful before per-shot processing
    like extract_frames_from_video / extract_character, so only the
    relevant shots need to be processed.
    Input: video_path (str).
    Optional params:
      - output_folder (str): defaults to
        D:\Files\Projects\Multi-Agent Orchestration Framework for Generative Video Editing\Output\<video name>_scenes\
      - threshold (float, default 27.0), min_scene_len (int, default 15).
    Output: {scene_count, scenes: [{index, start, end, duration, file}, ...],
    output_folder}
    Usage: split_scenes(video_path="D:\...\Sources\clip.mp4")


=========================================================
compositor-mcp tools (Tools\Compositor_MCP)
=========================================================

Composites multiple layers (images, transparent video/webm overlays, picture-in-
picture clips) onto a base video in a single ffmpeg filter_complex pass - position,
scale, opacity, visible time range and stacking order are all configurable per layer.
Requires ffmpeg/ffprobe on PATH, no extra Python dependencies.

28) compose_layers
